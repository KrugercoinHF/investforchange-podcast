# 🎙️ InvestForChange: The Shareholder Generation

> *A podcast series exploring how the SASSA Child Support Grant can be transformed into a lifelong investment vehicle for every South African child born from 2030.*

![Episodes](https://img.shields.io/badge/episodes-5-blue) ![License](https://img.shields.io/badge/license-CC_BY_4.0-green) ![Status](https://img.shields.io/badge/status-in_production-yellow)

## 📋 About

InvestForChange proposes redirecting the existing R580/month Child Support Grant into the **InvestForChange Sustainable DigiStocks Fund** — a diversified, low-risk investment vehicle — during a 36-month incubation period. After incubation, monthly dividends replace the cash grant, making every registered child a lifelong shareholder.
